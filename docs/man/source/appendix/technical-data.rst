A.2 Electrical
--------------

The nameplate at the back reads 230 V, 16 A and 900 W maximum. That is decoration; the rack's real draw is the sum of the parts in :ref:`Table A-2 <table-a-2>`.

.. _table-a-2:

.. table:: **Table A-2** Power draw

   +----------------------------------------+-----------------------------------------+--------------------+
   | Part                                   | Draw                                    | Server setting     |
   +========================================+=========================================+====================+
   | Base, while running                    | 60 W                                    | ``BasePowerW``     |
   +----------------------------------------+-----------------------------------------+--------------------+
   | Each drive being served                | 35 W                                    | ``PowerPerDriveW`` |
   +----------------------------------------+-----------------------------------------+--------------------+
   | Each idle drive, **ECO** DIP switch on | 20, 40, 60 or 80 % of the above, set in | –                  |
   |                                        | the BIOS; 40 % by default               |                    |
   +----------------------------------------+-----------------------------------------+--------------------+
   | Read and write traffic                 | Up to 80 W at full load                 | ``ActivityPowerW`` |
   +----------------------------------------+-----------------------------------------+--------------------+
   | Each running processor                 | 4 W per 64 lines per tick; 8 W on the   | –                  |
   |                                        | default HI clock                        |                    |
   +----------------------------------------+-----------------------------------------+--------------------+
   | Fans                                   | Auto 15–40 W; Low 8 W; High 60 W;       | –                  |
   |                                        | Manual 4–74 W; fan test 75 W. Each step |                    |
   |                                        | of the BIOS fan idle floor adds 8 W     |                    |
   +----------------------------------------+-----------------------------------------+--------------------+
   | UPS charging                           | 100 W × the **CHARGE** setting (25, 50, | ``UpsChargeW``     |
   |                                        | 100, 150 or 200 %), only while charging |                    |
   +----------------------------------------+-----------------------------------------+--------------------+

Drives, processors and traffic count only while storage is online. A rack with eight idle drives and Auto fans at 35 °C draws 60 + 15 + 8 × 35 = 355 W; with **ECO** on, 60 + 15 + 8 × 14 = 187 W.
