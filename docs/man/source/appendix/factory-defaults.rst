.. _app-b:

Appendix B: Factory defaults
============================

.. index::
   single: Factory defaults

This appendix lists the position of every control and the value of every setting as a new rack leaves the factory, and as a factory reset leaves it again. It is the page to keep open when a rack behaves strangely and you suspect that someone has been helpful. The controls are described in :ref:`4 Controls and indicators <ch-controls>`, the settings in :ref:`7 Configuration <ch-configuration>`, and the factory reset in :ref:`8 Maintenance <ch-maintenance>`.

B.5 Other state after a factory reset
-------------------------------------

Besides the controls and settings above, a factory reset leaves the rack in the following state. Drives and their contents, the chips, the cables, and all automation are kept.

.. _table-b-5:

.. table:: **Table B-5** Other state after a factory reset

   +--------------------------------+----------------------------------------------------+
   | Item                           | State                                              |
   +================================+====================================================+
   | Screen                         | The System program                                 |
   +--------------------------------+----------------------------------------------------+
   | I/O ports                      | All 32 empty                                       |
   +--------------------------------+----------------------------------------------------+
   | Logger channels                | All stopped, with no device; channel *n* points at |
   |                                | bank *n* + 3 and samples every 5 s                 |
   +--------------------------------+----------------------------------------------------+
   | Memory bookmarks               | Cleared                                            |
   +--------------------------------+----------------------------------------------------+
   | Scratch cells                  | All 0                                              |
   +--------------------------------+----------------------------------------------------+
   | Read, write and fault counters | 0                                                  |
   +--------------------------------+----------------------------------------------------+
   | Event log                      | Cleared, apart from the entry recording the reset  |
   +--------------------------------+----------------------------------------------------+
