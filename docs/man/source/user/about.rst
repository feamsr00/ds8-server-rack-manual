About this manual
=================
Each chapter is a page of its own, and the DS-8 OS chapter has one sub-page for each program. Tables and figures are numbered by chapter, so Table 8-2 is the second table in chapter 8. Procedures follow a fixed pattern: **Requirements** says what must be true before you begin, numbered steps follow, and **Result** describes what you should see at the end.

**Typographic conventions**

+--------------------------------------+------------------------------------------------------+
| Convention                           | Meaning                                              |
+======================================+======================================================+
| **HOME**, **BUS A**                  | Keys, switches and other labels printed on the rack  |
+--------------------------------------+------------------------------------------------------+
| ``Mode``, ``put``, ``DriveCapacity`` | Logic values, IC10 instructions and code, and server |
|                                      | settings                                             |
+--------------------------------------+------------------------------------------------------+
| *n*, *name*                          | A value that the rack fills in, or that you supply   |
+--------------------------------------+------------------------------------------------------+
| 8.4.1                                | A section number, as used in cross-references        |
+--------------------------------------+------------------------------------------------------+
| A linked chapter name                | A cross-reference to another chapter; select it to   |
|                                      | open that page                                       |
+--------------------------------------+------------------------------------------------------+
| **WARNING**, **CAUTION**, **NOTICE** | Safety notices, defined in                           |
|                                      | :ref:`2 Safety <security_warning>`                   |
+--------------------------------------+------------------------------------------------------+

Printing costs are not covered here.
